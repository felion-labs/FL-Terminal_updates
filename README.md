# Felion Terminal: releases

Installers for **Felion Terminal**: local shells, SSH, SFTP, serial and tunnels in one window.

**[Download the latest version →](https://github.com/felion-labs/FL-Terminal_updates/releases/latest)**

| System | File |
|---|---|
| Windows | `FelionTerminal-Setup-<version>.exe` (installer) or `FelionTerminal-Portable-<version>.exe` |
| macOS, Apple silicon | `FelionTerminal-<version>-mac-arm64.dmg` |
| macOS, Intel | `FelionTerminal-<version>-mac-x64.dmg` |
| Linux | `FelionTerminal-<version>-linux-x86_64.AppImage` or `FelionTerminal-<version>-linux-amd64.deb` |

Each release lists the SHA-256 of every file in `SHA256SUMS.txt`.

## What this repository is for

It holds the releases only, no source code. The app checks the latest release here shortly after it
starts and every six hours, and offers the right installer for your system when there is a newer
version. Nothing is downloaded or installed until you choose to.

Releases are published here automatically each time a new version is built.
